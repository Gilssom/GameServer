# Source and Publication Notice

## Learning foundation

The private full project began as study work based on Rookiss's Inflearn course,
"[C++과 언리얼로 만드는 MMORPG 게임 개발 시리즈] Part4: 게임 서버":

https://www.inflearn.com/course/언리얼-3d-mmorpg-4

No explicit permission to relicense or redistribute the complete course-derived
codebase as open source was identified during this review. Therefore this clean
repository deliberately excludes the course foundation and complete ServerCore.

## Independently authored portfolio extensions

The included excerpts demonstrate later work on:

- password hashing and account validation;
- database constraint verification;
- malformed and fragmented TCP stream scenarios;
- reproducible concurrent-load orchestration;
- measurement summaries and engineering reports.

Some excerpts reference types and interfaces from the excluded private project.
They are published as review material, not as a standalone or reusable product.

## Excluded material

- course sample and ServerCore foundation;
- Protobuf and RapidXML source or generated artifacts;
- binaries, libraries, PDBs, IDE caches, and build intermediates;
- raw logs, credentials, personal paths, and Unreal client code;
- Git history of the original study repository.

This notice records a conservative publication boundary and is not legal advice.
